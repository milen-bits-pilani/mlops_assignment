================================================================================
COMPONENT DETAILS
================================================================================

1. DATA LAYER
   - Source: UCI ML Repository
   - Format: CSV (303 samples, 14 features)
   - Storage: data/raw/heart_disease.csv
   - Processing: Cleaning, imputation, scaling

2. EDA LAYER
   - Script: src/eda/explore.py
   - Output: 5 visualization files
   - Location: data/eda/

3. MODEL LAYER
   - Algorithms: Logistic Regression, Random Forest
   - Evaluation: 5-fold CV, ROC-AUC primary metric
   - Tracking: MLflow
   - Output: models/best_model.pkl

4. API LAYER
   - Framework: FastAPI
   - Endpoints: /predict, /health, /metrics
   - Port: 8000
   - Replicas: 2

5. CONTAINER LAYER
   - Base: Python 3.12-slim
   - Size: ~1.2GB
   - Health Check: /health endpoint

6. DEPLOYMENT LAYER
   - Platform: Kubernetes (kind)
   - Services: API, Prometheus, Grafana, MLflow UI
   - Networking: LoadBalancer, NodePort

7. MONITORING LAYER
   - Metrics: Prometheus (scraping every 15s)
   - Visualization: Grafana (pre-configured)
   - Logging: Structured logs

================================================================================

│
├── API Deployment (2 replicas)
│   ├── Pod 1: heart-disease-api-xxx
│   └── Pod 2: heart-disease-api-yyy
│   └── Service: LoadBalancer (port 80 → 8000)
│
├── Prometheus Deployment
│   ├── Pod: prometheus-xxx
│   ├── Service: NodePort (9090)
│   └── ConfigMap: prometheus-config
│   └── RBAC: ServiceAccount, ClusterRole, ClusterRoleBinding
│
├── Grafana Deployment
│   ├── Pod: grafana-xxx
│   ├── Service: NodePort (3000)
│   └── ConfigMap: grafana-datasource

    ├── Pod: mlflow-ui-xxx
    ├── Service: NodePort (5000)
    └── Volume: mlruns (mounted)

================================================================================
NETWORKING
================================================================================

External Access (Port Forward):
  - API:          kubectl port-forward → localhost:8000
  - Prometheus:   kubectl port-forward → localhost:9090
  - Grafana:      kubectl port-forward → localhost:3000
  - MLflow:       kubectl port-forward → localhost:5000

Internal Communication:
  - Prometheus → API Pods: http://<pod-ip>:8000/metrics
  - Grafana → Prometheus:  http://prometheus-service:9090
  - API → Models:          /app/models/best_model.pkl
